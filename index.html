Publicar Sitio Web en GitHub Pages

Esta aplicación está diseñada en un único archivo autónomo (index.html) listo para alojarse gratis en GitHub Pages:

  1. Cree un repositorio público en GitHub (ejemplo: diagnostico-empresarial).
  2. Suba este archivo con el nombre exacto index.html en la raíz del repositorio.
  3. Vaya a Settings → Pages → Source, elija la rama main y carpeta / (root), y haga clic en Save.
  4. En menos de 1 minuto obtendrá su URL pública para compartir en estados y chats de WhatsApp.
